# Imatges de la web

Aquest directori està reservat als recursos visuals del web.

Fitxers previstos:
- `logo.svg` — logotip principal
- `hero.jpg` — imatge principal de portada
- `concurs.jpg` — imatge de la secció El concurs
- `fotos-01.jpg`, `fotos-02.jpg`, ... — fotografies
- `video-01.jpg`, `video-02.jpg`, ... — miniatures de vídeo

No cal modificar l'HTML per substituir una imatge: quan incorporem els recursos finals, només caldrà actualitzar els fitxers visuals i les referències corresponents.
